[옛이야기 스튜디오 — 바탕화면에서 쓰는 법]

압축을 풀고, 이 폴더를 바탕화면에 두세요.

■ 1) 영상 만들기 (대본·이미지·썸네일·음성·편집·내보내기)
    → index.html 을 더블클릭하세요. 그게 전부입니다!
    - 설치도, 검은 명령창도 필요 없습니다.
    - 필요한 API 키(Anthropic / 이미지 / 타입캐스트)는 화면의 ⚙에서 입력.

■ 2) 내 채널 "수익·분석"(구글 로그인)까지 보고 싶을 때만
    → 수익분석_켜기.bat 을 더블클릭하세요. (윈도우)
    - 파이썬 설치 필요 없음 (윈도우에 원래 있는 PowerShell 사용).
    - 자동으로 http://localhost:8000/index.html 이 열립니다.
    - 작은 창이 하나 뜨는데 켜 두세요(닫으면 종료).
    - 구글 OAuth "승인된 자바스크립트 원본"에  http://localhost:8000  추가.
    (맥이면 실행하기_맥.command 더블클릭)

  ※ 처음 실행 시 Windows 보안 경고가 뜨면 "추가 정보 → 실행"을 누르세요.
