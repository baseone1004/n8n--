# 옛이야기 곳간 · 민담·야담·옛날이야기 창작 프로그램

인터넷 창(브라우저)에서 바로 열어 쓰는, 우리 옛이야기 창작 도구입니다.
설치나 서버가 전혀 필요 없는 **순수 HTML/CSS/JS** 프로그램입니다.

## 쓰는 법

`index.html` 파일을 웹 브라우저(크롬, 엣지, 사파리 등)로 열기만 하면 됩니다.
(파일을 더블클릭하거나, 브라우저 창에 끌어다 놓으세요.)

## 기능

- **영감 얻기** — 시작하는 말·등장인물·때와 곳·일어나는 일·신묘한 물건·전하는 교훈을
  무작위로 뽑아 이야기 씨앗을 만들어 줍니다. 카드마다 ↻ 버튼으로 하나씩 다시 뽑거나,
  🎲 버튼으로 전부 새로 뽑을 수 있어요.
- **이야기 짓기** — 갈래(민담/야담/전설/신화/우화/옛날이야기)를 고르고 제목과 본문을
  씁니다. 뽑은 씨앗을 본문에 넣어 두고 시작할 수 있고, 글자 수도 실시간으로 보여 줍니다.
- **이야기 서재** — 지은 이야기를 카드로 모아 보고, 검색·읽기·고쳐 쓰기·지우기가 됩니다.
- **내보내기** — 이야기 한 편 또는 전체를 텍스트 파일로 내려받아 백업할 수 있어요.

## 저장 방식

모든 이야기는 **그 브라우저 안(localStorage)에만** 저장됩니다.
서버로 보내지 않으므로 안전하지만, 브라우저 데이터를 지우면 함께 사라집니다.
소중한 글은 **전체 내보내기**로 백업해 두세요.

## 🎬 영상 만들기 (초보자용 제작 마법사)

버튼 몇 번으로 **AI 유튜브 야담 영상 자료**를 만들고, **캡컷(CapCut)으로 넘겨 편집**하는 단계별 마법사입니다.

**🇰🇷 한국어 / 🇯🇵 일본어 채널 지원** — 상단 토글로 전환하면 주제·대본·태그·자막이 해당 언어로,
배경도 한국(조선·한복) / 일본(에도·기모노)으로, 워터마크도 「AI로 제작되었습니다 / AIで制作されました」로 바뀝니다.

1. **주제 고르기** — 9개 카테고리 중 하나 선택
2. **주제 추천** — 유튜브에서 잘 되는 주제 10개를 AI가 추천 → 하나 선택
3. **대본·정보** — 제목 · 제목 옆 태그 · 설명 · 태그 · 장면별 대본 자동 생성 (그 자리에서 편집)
4. **이미지 프롬프트** — 장면마다 나노 바나나용 영어 프롬프트 생성 + **그림체(화풍) 고르기**
   - 🇰🇷 한국: **반실사 웹툰(만화)풍 5종** (기본/진한 명암/부드러운 톤/디테일 강화/수채)
   - 🇯🇵 일본: **애니 셀화풍 5종** (기본/밝고 따뜻/차분한 톤/배경 디테일/우키요에)
   - 고른 화풍이 모든 장면에 적용되고, 직접 문구를 더 다듬을 수도 있습니다.
5. **이미지 생성** — 세 방법 중 선택: ⓐ Google Gemini 직접(나노 바나나, 장당 약 50~60원) · ⓑ **KIE.ai 크레딧**(⚙에서 방식 전환) · ⓒ **이미지 올리기**(드롭샷 등에서 뽑은 이미지를 업로드, 비용 0). 개별·전체 다운로드 지원. 프롬프트는 샷·포즈를 장면마다 다르게, 복식 일관, 글자 없음(SAFE) 규칙 적용.
   - 💰 비용 팁: 이미지를 많이 쓰면 직접 API는 비용이 커집니다. KIE 크레딧이나 드롭샷 Pro(나노 바나나 무제한)에서 뽑아 업로드하면 저렴/무료. (KIE는 서버용 API라 브라우저에서 CORS로 막히면 웹에서 뽑아 업로드하세요.)
6. **썸네일** — 결말을 숨긴 **썸네일 카피 4종**(좌측 4줄/하단 2줄) 생성 → 고른 카피에 맞춰 **썸네일 이미지**(글자 자리 비움, 이미지엔 글자 없음) 생성·다운로드
7. **음성·자막** — **Inworld TTS**로 장면별 감정을 반영한 음성을 자동 생성하고, 실제 음성 길이에 맞춰 자막(SRT)을 자동 동기화합니다. 직접 만든 음성 업로드도 지원합니다.
8. **편집·미리보기 (캡컷 스타일)** — 장면별 줌 인/줌 아웃·자막·길이 편집, 워터마크 문구 편집, **▶ 재생 미리보기**, 인트로는 영상처럼 강조 + **인트로 클립(webm) 저장** + **🎥 Grok 인트로 영상 프롬프트**(이미지→영상 프롬프트) 생성
9. **캡컷 내보내기** — 이미지 · 썸네일 · 음성 · 자막(SRT) · 대본 · 유튜브 정보를 **ZIP 한 폴더**로 내려받아 캡컷에서 최종 편집

> 대본·이미지·썸네일·영상변환 프롬프트는 제공된 정제본(v11.3 / flow v5.3 / 썸네일 / Grok 인트로) 규칙을
> 반영해 생성됩니다: 제목 패턴·인트로 6문장·7단계 골격·고정 마무리 멘트·스포일러 금지·순한글(일본어면 쉬운 일본어) 등.

> **API 키 입력**: 화면 상단 <b>🔑 API 키</b> 버튼(또는 키가 없을 때 뜨는 안내 배너)에서 넣습니다.

### 필요한 키 (⚙ 키 설정)
- **Anthropic API 키** — 주제·대본·프롬프트 생성 (텍스트)
- **Google AI(Gemini) API 키** — 이미지(나노 바나나) + 음성(TTS). 키 하나로 둘 다.
  발급: https://aistudio.google.com/apikey

### 캡컷에서 하는 일 (ZIP 안 `capcut_guide.txt`에도 안내)
- `images/`를 번호 순서대로 타임라인에 올리고, `audio/`의 같은 번호 음성을 아래에 맞춤
- 인트로 외 이미지는 **줌 인/줌 아웃** 효과
- `subtitles.srt`를 자막으로 가져오기
- 왼쪽 위에 텍스트로 **"AI로 제작되었습니다"** 삽입
- `youtube_info.txt`에서 제목·설명·태그 복사

> 진짜 영상 컷 편집·최종 MP4 렌더링은 캡컷이 담당합니다. 이 프로그램은 **캡컷에 넣을 자료를
> 자동으로 만들어 주는** 역할이에요. 모든 생성은 브라우저에서 본인 키로 이뤄지며,
> claude.ai에 게시된 미리보기(Artifact)에서는 보안 정책상 AI 호출이 막히니 **로컬 파일로 실행**하세요.

## 📊 유튜브 분석 · 벤치마킹

**유튜브 분석** 탭 (YouTube Data API v3 키 필요, 공개 지표만).
- **내 채널 분석** — @핸들/URL/ID → 구독자·총 조회수·영상 수 + 최근 영상별 조회수·좋아요·댓글
- **떡상 벤치마킹** — 검색어로 **최근 7일** 조회수 상위 영상 10개 → 썸네일·조회수·채널, 제목을 눌러 바로 대본 제작으로 연결
- ⚠ **수익(매출)은 API 키로 볼 수 없습니다.** 수익·시청 지속시간 등 상세 분석은 [YouTube 스튜디오](https://studio.youtube.com)(내 계정 로그인)에서 확인하세요.

## 대본 공방 (AI 스튜디오)

**대본 공방** 탭은 Anthropic Claude API로 야담 콘텐츠 제작 파이프라인을 실제로 돌리는 채팅 도구입니다.
세 가지 모드를 제공합니다.

1. **① 야담 대본** — 제목/카피 또는 장르를 주면 베리에이션 → 인트로 → 작명 → 반전 6개 →
   챕터별 집필까지 진행합니다. 목표 분량은 1시간 30분~2시간(35,000~46,000자).
2. **② 이미지 프롬프트** — 완성된 대본을 붙여넣으면 챕터별 Google Flow / 나노 바나나 프로용
   이미지 프롬프트를 만들어 줍니다. `화풍 프리셋`으로 그림체(조선 반실사 웹툰풍 등)를 골라 넣습니다.
3. **③ 썸네일** — 썸네일 브리프/대본으로 시니어 야담 채널용 썸네일 카피 + 이미지 프롬프트를 기획합니다.

### 쓰기 전 준비
- **⚙ 설정**에서 **Anthropic API 키**를 입력하세요. 키는 이 브라우저(localStorage)에만
  저장되며 어디에도 전송되지 않습니다. 키 발급: https://console.anthropic.com/settings/keys
- **모델**을 고릅니다. Opus판 프롬프트는 opus 계열, 가벼운 진행은 sonnet 계열을 권장합니다.
- 긴 챕터는 한 번에 다 안 나올 수 있어요. 응답이 끊기면 **계속** 버튼(또는 "계속" 입력)으로 이어집니다.

> 참고: 이 프롬프트들은 원래 코드 실행이 되는 Claude Project용이라, 브라우저 환경에서는
> 코드 강제(작명 스크립트·검증) 부분을 모델이 규칙대로 인라인 수행하도록 조정했습니다.
> 산출물은 파일이 아니라 채팅 본문으로 출력되며, 각 답변의 **복사** 버튼이나
> **대화 내보내기**(.md)로 저장할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 화면 구조 |
| `styles.css` | 한지(韓紙) 느낌의 디자인 |
| `data.js` | 옛이야기 씨앗 자료(인물·배경·소재 등) |
| `app.js` | 뽑기·저장·서재 등 동작 |
| `prompts.js` | 대본 공방의 세 프롬프트 시스템 번들 + 화풍 프리셋 |
| `studio.js` | 대본 공방 채팅·Claude API 스트리밍 동작 |
| `producer.js` | 영상 만들기 마법사 (주제→대본→이미지→음성·자막→캡컷 ZIP) |

씨앗 자료를 늘리고 싶으면 `data.js`의 목록에 문장을 추가하면 됩니다.
