# 옛이야기 곳간 · 민담·야담·옛날이야기 창작 프로그램

인터넷 창(브라우저)에서 바로 열어 쓰는, 우리 옛이야기 창작 도구입니다.
설치나 서버가 전혀 필요 없는 **순수 HTML/CSS/JS** 프로그램입니다.

## 쓰는 법

`index.html` 파일을 웹 브라우저(크롬, 엣지, 사파리 등)로 열기만 하면 됩니다.
(파일을 더블클릭하거나, 브라우저 창에 끌어다 놓으세요.)

## 기능

- **영감 얻기** — 시작하는 말·등장인물·때와 곳·일어나는 일·신묘한 물건·전하는 교훈을
  무작위로 뽑아 이야기 씨앗을 만들어 줍니다. 카드마다 ↻ 버튼으로 하나씩 다시 뽑거나,
  🎲 버튼으로 전부 새로 뽑을 수 있어요.
- **이야기 짓기** — 갈래(민담/야담/전설/신화/우화/옛날이야기)를 고르고 제목과 본문을
  씁니다. 뽑은 씨앗을 본문에 넣어 두고 시작할 수 있고, 글자 수도 실시간으로 보여 줍니다.
- **이야기 서재** — 지은 이야기를 카드로 모아 보고, 검색·읽기·고쳐 쓰기·지우기가 됩니다.
- **내보내기** — 이야기 한 편 또는 전체를 텍스트 파일로 내려받아 백업할 수 있어요.

## 저장 방식

모든 이야기는 **그 브라우저 안(localStorage)에만** 저장됩니다.
서버로 보내지 않으므로 안전하지만, 브라우저 데이터를 지우면 함께 사라집니다.
소중한 글은 **전체 내보내기**로 백업해 두세요.

## 파일 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 화면 구조 |
| `styles.css` | 한지(韓紙) 느낌의 디자인 |
| `data.js` | 옛이야기 씨앗 자료(인물·배경·소재 등) |
| `app.js` | 뽑기·저장·서재 등 동작 |

씨앗 자료를 늘리고 싶으면 `data.js`의 목록에 문장을 추가하면 됩니다.
