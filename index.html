⚠ KIE API는 서버용이라 브라우저에서 막힐(CORS) 수 있어요. 안 되면 KIE 웹에서 이미지를 뽑아 이미지 올리기로 넣으세요.

Inworld TTS (감정/속도 자동 적용)

✅ 황태후형 목소리 ID가 기본으로 들어 있습니다. 위에는 Inworld Portal의 API Keys → Basic에서 복사한 Base64 credentials만 넣으세요. 장면별 감정·속도는 자동 적용됩니다.

YouTube 로그인·업로드

Google Cloud에서 만든 웹 애플리케이션 OAuth 클라이언트 ID를 입력하세요. 클라이언트 보안 비밀번호는 입력하지 않습니다. 저장한 뒤 왼쪽의 내 채널 분석에서 Google 로그인을 진행하세요.

키는 이 브라우저에만 저장됩니다. Anthropic: console.anthropic.com · Google AI: aistudio.google.com/apikey · KIE: kie.ai · Inworld: platform.inworld.ai

이야기 서재

아직 지은 이야기가 없어요. 이야기 짓기에서 첫 이야기를 남겨 보세요.

Opus판 프롬프트는 opus 모델, 가벼운 진행은 sonnet 모델을 추천합니다. 키는 console.anthropic.com에서 발급.

화풍 프리셋 (선택하면 입력창에 삽입)

내 채널 분석 · 수익

구글로 로그인하면 최근 28일 조회수·시청시간·구독자 증가·예상 수익이 바로 나옵니다. (반드시 수익분석_켜기.bat=localhost로 열어야 로그인돼요.)

※ 예상 수익은 수익 창출 채널일 때만. 필요한 API 사용 설정: Google Cloud에서 YouTube Analytics API + YouTube Data API v3.

다른 채널 분석 (인기 채널 자동)

이 메뉴를 열면 자동으로 인기 야담 채널들을 구독자순으로 분석해요. 핸들·URL 입력 필요 없어요. 검색어를 바꾸면 그걸 기억합니다.

떡상 벤치마킹 (최근 7일 급상승)

이 메뉴를 열면 자동으로 최근 7일 조회수 상위 영상이 떠요. 검색어를 바꾸면 그걸 기억합니다. 제목을 눌러 바로 대본으로.
